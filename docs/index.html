01 — De dónde viene

El oficio no depende
de la herramienta.

Creative Architect nace de higgsfield-estudio, el plugin de Enrique Rocha para hacer UGC, avatares, fotos de producto y anuncios. Ese plugin tenía dos cosas mezcladas: el oficio (cómo se escribe un prompt que no sale genérico, cómo se respeta un producto real, cómo se arma un gancho) y el proveedor (nombres de herramientas, modelos, un candado de créditos).

Aquí se separaron. Las skills piden intenciones, como "editar con la foto real como referencia" o "video desde imagen", y una capa de proveedores las traduce a Higgsfield, Magnific, OpenAI o el que añadas. El mismo criterio hoy con uno y mañana con otro.

02 — Cómo piensa

Un prompt corto no es libre.
Es uno donde el modelo elige por ti.

Y el modelo siempre elige el promedio. Por eso cada imagen se escribe en once bloques, con lo innegociable arriba.

  1. 01ConceptoFoto publicitaria para anuncio de Instagram, cálida y apetecible.
  2. 02SujetoFrasco de vidrio ámbar de 250 g, etiqueta kraft mate, tapa negra.
  3. 03ComposiciónPlano medio, frasco al tercio derecho, tercio izquierdo vacío.
  4. 04LuzLateral suave desde la izquierda, tipo ventana grande, cálida.
  5. 05FondoCemento pulido claro, desenfocado, sin objetos.
  6. 06MaterialesVidrio con brillo suave, metal mate, polvo de café.
  7. 07Lente85 mm a f/2.8. Enfoque nítido en la etiqueta.
  8. 08PaletaÁmbar, crema y negro profundo. Sin azules.
  9. 09EstiloEditorial de gastronomía, grano fino. Técnica, no apellidos.
  10. 10CalidadAlto detalle en la etiqueta. Sin "8k obra maestra".
  11. 11Qué evitarSin texto, sin logotipos ajenos, sin reflejos imposibles.

04 — Proveedores

Funciona con lo que tengas.

Al empezar mira qué hay: conectores MCP, CLIs y variables de entorno, sin imprimir nunca una llave. Si no hay ninguno, te entrega el prompt listo para pegar.

detectado

Higgsfield

detectado

MCP oficial (OAuth) · API REST

Escalado, reiluminado, expansión y detalle de imagen.

detectado

OpenAI

API · OPENAI_API_KEY

El tuyo

05 — Instalar

Dos comandos y listo.

Claude Code
> /plugin marketplace add Hainrixz/creative-architect
> /plugin install creative-architect@creative-architect
✓ creative-architect 1.0.1 instalado
> /creative-architect fotos de mi crema para Meta en 4:5
  1. Instala con los dos comandos. Desde la terminal también: claude plugin marketplace add Hainrixz/creative-architect y claude plugin install creative-architect@creative-architect.
  2. Conecta un proveedor: el conector de Higgsfield en claude.ai, el MCP de Magnific o tu OPENAI_API_KEY en el shell. Opcional.
  3. Pide en español normal. El agente decide el oficio, la luz y el lente.

06 — Lo que nunca hace

Autónomo, no imprudente.

  • No entrena caras ni clona voces sin el permiso de quien las presta.
  • No inventa testimonios ni experiencia que no le pasó a nadie.
  • De la competencia toma la estructura, nunca el contenido.
  • No compra créditos, no publica ni borra nada remoto si no se lo pides.
  • El costo es una nota de una línea, no un candado.
  • Nunca imprime ni guarda una llave.
